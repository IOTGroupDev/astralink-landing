# AstraLink landing

Главная страница на **Next.js 16.4 / React 19 / TypeScript / Tailwind CSS 4**.

Визуальная композиция основана на [Moonly](https://moonly.app/), тексты, факты, ссылки и экраны приложения взяты с [AstraLink](https://www.astra-link.app/). Язык оригинала сохранён. Реализована только главная; ссылки на калькуляторы, статьи и юридические страницы ведут на действующий AstraLink.

## Запуск

Требуется Node.js 22.13+ (разработка проверена на Node.js 24).

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000.

```bash
npm run check       # тесты валидации, TypeScript и production-сборка
npm start           # запуск собранного приложения
```

## Где менять содержимое

- `src/lib/content.ts` — функции, FAQ, ссылки, инструменты и календарь.
- `src/lib/navigation.ts` — семь разделов шапки и все 35 ссылок исходных подменю.
- `src/app/page.tsx` — порядок секций и остальные тексты главной.
- `src/app/globals.css` — токены Tailwind, композиция и адаптивные стили.
- `src/components/` — меню, карточка функции и форма.
- `public/images/` — локальные оптимизированные изображения.

## Оптимизация

- Главная пререндерится при сборке; для её показа не нужны запросы к CMS или API.
- Только меню и форма являются клиентскими компонентами. FAQ и раскрытие описаний используют HTML `details`.
- Нет библиотек анимации, иконок, слайдеров, трекеров, внешних шрифтов, iframe или фонового видео.
- Один локальный WOFF2 через `next/font/local`, с preload и `font-display: swap`.
- Собственные широкая и мобильная обложки, сгенерированные через ImageGen и оптимизированные в WebP. Обложка загружается сразу с `fetchPriority="high"`, остальные изображения — лениво. Серверный `getImageProps` сохраняет адаптивные размеры и AVIF/WebP Next.js без гидратации компонентов изображений.
- Статические импорты дают изображениям хеш содержимого: длительное кеширование не мешает замене картинок при следующем деплое.
- Размеры изображений заданы явно; декоративные SVG рендерятся на сервере.
- `content-visibility` откладывает отрисовку длинных секций. Анимации отключаются при `prefers-reduced-motion`.
- Metadata, canonical, Open Graph, Twitter Card, JSON-LD, `robots.txt`, `sitemap.xml`, SVG favicon.
- Семантические заголовки, подписи полей, состояния фокуса, skip link, клавиатурное меню и сообщения формы через `aria-live`.
- Полная навигация AstraLink с ES: все ссылки подменю есть в серверном HTML. На компьютере — светлые панели со скриншотами приложения, на мобильном — раскрываемые разделы. Работают клавиатура, Escape и закрытие по клику снаружи; изображения меню загружаются лениво.

## Форма раннего доступа

Скопируйте `.env.example` в `.env.local` и заполните `WAITLIST_ENDPOINT` адресом существующего backend. При необходимости укажите `WAITLIST_API_TOKEN`; он используется только на сервере. Backend получает JSON и должен вернуть HTTP 2xx с `{ "ok": true }` после сохранения заявки. Пример структуры:

```json
{
  "email": "person@example.com",
  "birth_date": "2000-01-01",
  "first_name": "",
  "gender": "",
  "seeking": "",
  "consent": true,
  "lang": "en",
  "source_url": "/"
}
```

Без настройки endpoint форма показывает сообщение и ссылку на действующую регистрацию AstraLink. Заявки не сохраняются в браузере, успешная регистрация не имитируется. Маршрут проверяет email, календарную дату, возраст 13+, согласие, разрешённые значения и honeypot; использует ограничение тела запроса, проверку Origin и таймаут upstream. Защиту от массовых запросов следует включить на backend или на уровне хостинга.

Перед деплоем задайте `NEXT_PUBLIC_SITE_URL` конечным доменом, чтобы canonical и sitemap соответствовали размещению. Для работы API и оптимизации изображений нужен Next.js-совместимый хостинг; `output: export` не используется.
